2. Box-sizing: content-box vs border-box

content-box
width: 300px + 24px padding + 2px border = 352px rendered.
← 352px wide (300+24+24+2+2)
border-box
width: 300px (padding & border included) = 300px exactly.
← 300px wide (padding+border inside)

3. Specificity showdown

This paragraph has an element selector (p), a class (.spec-class), and an ID (#spec-id).

Winner: ID selector — specificity (1,0,0) beats class (0,1,0) and element (0,0,1).

  • #spec-id → specificity: 1,0,0 (wins)
  • .spec-class → specificity: 0,1,0
  • p (element) → specificity: 0,0,1

🔍 The ID rule sets color to #2c5282 (blue), which overrides the class (red) and element (green).
